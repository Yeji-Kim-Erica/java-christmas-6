
우아한테크코스 웹 백엔드 최종 코딩테스트 대비를 위한 연습용 프로젝트: 크리스마스 프로모션

---

## 🎯 프로젝트 개요

우아한테크코스 최종 코딩테스트를 대비하기 위한 연습용 프로젝트입니다.  
크리스마스 프로모션 프로그램을 구현합니다.

---

## 📝 구현 기능 목록

### 1. 주문 내역 입력
- [ ] **식당 예상 방문 날짜 입력**
    - 시작 문구 출력 (형식: `안녕하세요! 우테코 식당 12월 이벤트 플래너입니다.`)
    - 입력 안내 문구 출력 (형식: `12월 중 식당 예상 방문 날짜는 언제인가요? (숫자만 입력해 주세요!)`)
    - 식당 예상 방문 날짜 숫자 입력
      - 1~31 사이의 숫자만 입력 가능
    - **(예외 처리)** 방문 날짜 유효성 검사: `IllegalArgumentException` (형식: `[ERROR] 유효하지 않은 날짜입니다. 다시 입력해 주세요.`)
      - [ ] 입력 값이 존재하지 않는 경우: 빈 문자열, 공백 문자열, Null
      - [ ] 숫자로 변환이 불가한 경우: 숫자가 아닌 문자 포함
      - [ ] 숫자가 범위를 벗어난 경우: 숫자가 1 미만 또는 31 초과
    - 예외 발생 시, 식당 예상 방문 날짜 입력 프로세스 다시 시작 (선택사항)
    - 식당 예상 방문 날짜 저장

- [ ] **주문 메뉴 및 수량 입력**
    - 입력 안내 문구 출력 (형식: `주문하실 메뉴와 개수를 알려 주세요. (e.g. 해산물파스타-2,레드와인-1,초코케이크-1)`)
    - 주문 메뉴와 수량 입력
      - 메뉴판에 존재하는 메뉴만 주문 가능
        - 메뉴판
        ```text
          <애피타이저>
          양송이수프(6,000), 타파스(5,500), 시저샐러드(8,000)
    
          <메인>
          티본스테이크(55,000), 바비큐립(54,000), 해산물파스타(35,000), 크리스마스파스타(25,000)
    
          <디저트>
          초코케이크(15,000), 아이스크림(5,000)
    
          <음료>
          제로콜라(3,000), 레드와인(60,000), 샴페인(25,000)
        ```
      - 메뉴의 개수는 1 이상
      - 메뉴 주문 형식 준수 (예시: `{메뉴 이름}-{수량}`, 여러 개의 메뉴 입력 시 `,`로 연결)
      - 중복 메뉴 입력 불가
      - 음료만 주문 시, 주문할 수 없음
      - 메뉴는 한 번에 최대 20개까지만 주문 가능 (총 수량이 20개를 넘을 수 없음)
    - **(예외 처리)** 주문 입력 유효성 검사: `IllegalArgumentException` (형식: `[ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요.`)
      - [ ] 입력 값이 존재하지 않는 경우: 빈 문자열, 공백 문자열, Null
      - [ ] 메뉴 주문 형식이 지켜지지 않은 경우: `{메뉴명}-{수량}`, 연결 문자 `,`
    - **(예외 처리)** 메뉴명 유효성 검사: `IllegalArgumentException` (형식: `[ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요.`)
      - [x] 메뉴판에 해당 메뉴명이 존재하지 않는 경우
      - [ ] 메뉴가 중복 입력된 경우
      - [ ] 음료만 주문하는 경우: 음료 단독 주문 불가
    - **(예외 처리)** 주문 수량 유효성 검사: `IllegalArgumentException` (형식: `[ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요.`)
      - [ ] 숫자로 변환이 불가한 경우: 숫자가 아닌 문자 포함
      - [ ] 단일 메뉴 수량이 범위를 벗어난 경우: 최소 1개 이상 주문
      - [ ] 총 수량이 범위를 벗어난 경우: 모든 메뉴의 수량의 합은 20개 이하까지 주문 가능
    - 예외 발생 시, 주문 메뉴 및 수량 입력 프로세스 다시 시작 (선택사항)
    - 주문 메뉴명, 수량 저장

### 2. 주문 금액 계산 및 이벤트 적용
- [x] **총주문 금액 계산**
    - 메뉴판을 참고해 총 주문 금액 계산: 메뉴 가격 * 수량
    - 총주문 금액이 10,000원 이상이라면 이벤트 적용 프로세스 진행
- [x] **크리스마스 디데이 할인 계산**
    - 이벤트 기간: 2023.12.1 ~ 2023.12.25
    - 1,000원으로 시작해 크리스마스가 다가올수록 날마다 할인 금액이 100원씩 증가
- [x] **평일 할인 계산**
    - 평일: 일요일~목요일
    - 디저트 메뉴를 메뉴 1개당 2,023원 할인
- [ ] **주말 할인 계산**
    - 주말: 금요일, 토요일
    - 메인 메뉴를 메뉴 1개당 2,023원 할인
- [ ] **특별 할인 계산**
    - 별이 있는 날짜: 3, 10, 17, 24, 25, 31 (매주 일요일 + 크리스마스)
    - 총주문 금액에서 1,000원 할인
- [ ] **증정 이벤트 계산**
    - 할인 전 총주문 금액이 12만 원 이상일 때
    - 샴페인 1개 증정
- [ ] **총혜택 금액 계산**
    - 총혜택 금액 = 할인 금액의 합계 + 증정 메뉴의 가격
- [ ] **할인 후 예상 결제 금액 계산**
    - 할인 후 예상 결제 금액 = 할인 전 총주문 금액 - 할인 금액(증정 메뉴의 가격 포함 X)
- [ ] **12월 이벤트 배지 계산**
    - 혜택 금액에 따른 12월 이벤트 배지
      - 5천 원 이상: 별
      - 1만 원 이상: 트리
      - 2만 원 이상: 산타

### 3. 이벤트 내역 출력
- [ ] **이벤트 혜택 미리 보기 안내 문구 출력**
    - 출력 시작 안내 문구 출력 (형식: `12월 {방문날짜}일에 우테코 식당에서 받을 이벤트 혜택 미리 보기!`)
- [ ] **주문 메뉴 출력**
    - 제목 출력 (형식: `<주문 메뉴>`)
    - 내역 출력 (형식: `{메뉴명} {수량}개`)
- [ ] **할인 전 총주문 금액 출력**
    - 제목 출력 (형식: `<할인 전 총주문 금액>`)
    - 금액 출력 (형식: `{할인 전 총주문 금액}원`, 금액 형식 `###,###`)
- [ ] **증정 메뉴 출력**
    - 제목 출력 (형식: `<증정 메뉴>`)
    - 내용 출력
      - 증정 이벤트에 해당하는 경우 (형식: `{메뉴명} {수량}개`)
      - 증정 이벤트에 해당하지 않는 경우 (형식: `없음`)
- [ ] **혜택 내역 출력**
    - 제목 출력 (형식: `<혜택 내역>`)
    - 내역 출력
      - 적용된 이벤트가 존재하는 경우 (형식: `{혜택명}: -{할인 금액}원`, 금액 형식 `###,###`)
        - 혜택 목록
          - 크리스마스 디데이 할인
          - 평일/주말 할인
          - 특별 할인
          - 증정 이벤트
        - 증정 이벤트의 경우, 할인 금액 계산 방법: 증정 메뉴 가격 * 수량
      - 적용된 이벤트가 하나도 없는 경우 (형식: `없음`)
- [ ] **총혜택 금액 출력**
    - 제목 출력 (형식: `<총혜택 금액>`)
    - 금액 출력 (형식: `-{총혜택 금액}원`, 금액 형식 `###,###`)
- [ ] **할인 후 예상 결제 금액 출력**
    - 제목 출력 (형식: `<할인 후 예상 결제 금액>`)
    - 금액 출력 (형식: `{할인 후 예상 결제 금액}원`, 금액 형식 `###,###`)
- [ ] **12월 이벤트 배지 출력**
    - 제목 출력 (형식: `<12월 이벤트 배지>`)
    - 내용 출력
      - 이벤트 배지가 부여된 경우 (형식: `{이벤트 배지명}`)
      - 이벤트 배지가 부여되지 않는 경우 (형식: `없음`)
